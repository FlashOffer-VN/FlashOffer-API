# Prompt Feature Notes

Thư mục này chứa các bản ghi thay đổi và ghi chú cho mỗi prompt feature đã thực thi.

Mục đích:
- Ghi lại những file đã tạo hoặc sửa khi một prompt feature chạy.
- Giữ lịch sử ngắn gọn cho mỗi prompt feature.
- Giúp review và audit các thay đổi trước khi commit.

Quy tắc:
- Tạo file note cho mỗi prompt feature theo dạng: `NN-<tên-prompt>.md`.
- File note nên mô tả:
  - Tên prompt
  - Mục tiêu
  - Các file đã thêm/sửa
  - Các lưu ý quan trọng

Ví dụ:
- `01-Example-Prompt.md` cho prompt mẫu Category.
