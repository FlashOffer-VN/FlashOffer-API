# Project Requirements

- Target: .NET 9 / ASP.NET Core Web API
- Response format: sử dụng `ApiResponse<T>` và `ApiControllerBase` (xem `02-standard-response.md`)
- Layers: Domain / Application / Infrastructure / WebApi — KHÔNG để business logic ở WebApi
- Dependency injection: register services trong đúng layer (`DependencyInjection.cs` per project)
- AutoMapper: mapping định nghĩa trong `MappingProfile.cs` và scan tự động
- Validators: FluentValidation, register via `AddValidatorsFromAssembly`
- Repository: sử dụng `IRepository<T>` generic và `GenericRepository`
- Encoding: tất cả prompt/md phải là UTF-8 (no BOM), không có NUL bytes
- Files generated by LLM: do not commit secrets; store connection strings in env/user-secrets
